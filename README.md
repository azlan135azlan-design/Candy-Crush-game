
# Candy Crush Game 🎮

A Candy Crush-style game developed using **C++ and SFML** as our Programming Fundamentals semester project.

## About the Project

This project is inspired by the popular Candy Crush game. Players match candies, complete different levels, earn points and use boosters to improve their gameplay.

## Features

- **Candy Matching System:** Match candies to clear them from the board.
- **Gravity and Refill:** New candies fall into empty spaces after matches.
- **Levels and Scoring:** Complete levels earn points and collect stars.
- **Animations:** Visual effects and animations using SFML.
- **Player Profiles:** Save player names and game progress.
- **Booster System:** Use Shuffle and +5 Moves boosters.
- **Booster Shop:** Purchase boosters using earned coins.
- **Endless Mode:** Play and try to achieve a high score.
- **Leaderboard:** Save and display the top score

## Technologies Used

- C++
- SFML (Simple and Fast Multimedia Library)
- File Handling
- Object-oriented graphics and game programming concept

## How to Play

1. Start the game.
2. Select a level or choose Endless Mode.
3. Match candies to achieve the level's goal.
4. Use boosters when needed.
5. Earn stars and coins as you progress.
